# T010 主頁面改版、組隊與出征地圖

（2026-11-11 白天依 Jimmy 手機留言加開，不在原本夜間排程內）

## 目標
把原本「角色列表 + 出征按鈕」的主畫面，改成放置型遊戲常見的大廳：動態背景、會動的主頁角色、左上帳號設定、右側功能按鈕；並加上組隊編排、三章節出征地圖、劇情回顧，支援手機橫放。

## 範圍
做：
- 主頁（LobbyScene）：動態背景（雲、落葉／竹葉／雪／燈籠飄動），依進度或活動取得、可切換；前景是玩家選的狗狗，每 3 秒換動作（站著呼吸、搖尾巴、跳、東張西望、坐下、打盹），點牠會跳一下。
- 左上「帳號與設定」：語音、音樂、推播開關，畫質（低／中／高，低畫質關掉飄落特效），官方網站、討論區連結，優惠碼兌換。
- 右側按鈕：劇情、組隊、出征；左側：換背景；下方：出征狀態與收成。
- 組隊（TeamScene）：3 格隊伍 + 官方已釋放的全部角色（8 隻），未擁有的 3 隻暗色顯示；點角色可加入／移出隊伍、設為主頁角色。
- 出征地圖（CampaignScene）：3 章 × 5 小節，點與線連接，第 5 關是大隻 Boss（高山犬、大丹犬、藏獒）。打過一關開下一關，打倒 Boss 開下一章。
- 出征選隊伍（ExpeditionScene）：預設帶入組隊編排的隊伍。
- 劇情（StoryScene）：過特定關卡後自動播放（情境圖 + 對話），之後在「劇情」重看；未解鎖的顯示 ？？？ 與條件。
- 手機橫放：直式 390×844、橫式 844×390，轉向時自動重新排版。

不做：
- 真正的語音、音樂、推播、帳號系統（只有介面與開關）。
- 優惠碼後端（碼寫在 `src/data/backgrounds.ts`）。
- 存檔（等 T006，目前重新整理會回到初始狀態）。
- 正式美術（全部是程式畫的佔位圖）。
