# T022 訓練場每日小遊戲

## 目標
訓練場多一個每天玩一次的小遊戲「接飛盤」：帶狗狗跑位接飛盤，給少量經驗，也讓狗狗有可愛的互動。

## 範圍
做：
- 訓練場右上角「小遊戲」按鈕（在「寄宿」左邊），今天還沒玩會亮紅點。
- 先選一隻擁有的狗上場（預設主頁那隻；牠滿級就換一隻還能拿經驗的）。
- 一場 8 個飛盤，一個一個從場邊丟進來，地上的影子是落點；手指按著左右滑（或移動滑鼠）狗狗就往那邊跑，落地時在落點附近就接到。全程不用點擊。
- 每天第一次玩有獎勵（05:00 換日，和每日任務同一個時間）：上場的狗拿經驗，全部接到再送一個零食。之後可以再玩，只更新最佳紀錄、沒有獎勵。
- 存檔：`GameState.frisbee = { day, best }`。

不做：
- 其他種類的小遊戲、排行榜、每日任務裡加「玩小遊戲」。
- 主頁「訓練」按鈕上的紅點。

## 驗收標準
- [x] 訓練場進得去小遊戲，按鈕不和「寄宿」重疊
- [x] 可以換上場的狗，照落點跑就接得到，結算顯示接到幾個、經驗與升級
- [x] 同一天第二次玩沒有獎勵；重新整理後仍記得今天玩過與最佳紀錄
- [x] 所有新增邏輯有單元測試，`npm test` 全綠
- [x] 相關畫面有 Playwright 截圖，附在 PR

## 設計說明
- 規則全在 `src/logic/frisbee.ts`（純函式）：`frisbeePlan` 用種子排出 8 個飛盤的時間與落點（相鄰落點差 0.15～0.5 個場地寬，保證丟出來才開始跑也到得了）、`frisbeePos` 算飛行位置、`moveDog` 算狗狗跑位、`finishFrisbee` 結算。
- 畫面 `src/scenes/FrisbeeScene.ts`，排版 `src/logic/frisbeeLayout.ts`。時間用真實時間算；兩格畫面隔超過 0.5 秒（切到別的 App）就當成暫停。
- 暫定數值：一場 8 個、間隔 1.9 秒、飛行 1.7 秒漸快到 1.35 秒、狗狗一秒跑 0.7 個場地寬、落點左右各 6.5% 場地寬算接到。
- 獎勵：經驗 =「已通關關卡裡經驗最高那一關」×（0.5 + 0.15 × 接到幾個），全部接到是 1.7 場；全部接到再送該章節的經驗零食 ×1。
- 背景用玩家目前選的主頁背景。

## 需要 Jimmy 決定的事
- 飛盤數量、速度、接到的判定範圍會不會太簡單或太難。
- 獎勵多寡（現在約 0.5～1.7 場出征的經驗，加一個零食）。
- 一天一次夠不夠；再玩沒有獎勵可不可以。
- 之後要不要加其他小遊戲輪流出現。
