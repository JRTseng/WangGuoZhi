## 做了什麼

- **入口**：主頁右上那一排最左邊多一顆「老鼠幫」按鈕，只有在活動時段、而且已經打倒第一章頭目之後才會出現；今天還有波數沒打就亮紅點。
- **活動畫面**：左邊是鼠老大阿刺帶著小弟，右邊寫時段、今天還剩幾波、強度、獎勵，按「出擊」選隊伍開戰。
- **時段**：現在全天都有。之後要改成每天中午，只要改 `src/logic/ratRaid.ts` 的 `RAT_RAID.hours`（例如 `[{ from: 12, to: 14 }]`，可以寫好幾段）。
- **次數**：每天（早上 5 點換日）可以打贏 3 波，不花體力、不算主線的每日次數。打輸沒有獎勵也沒有經驗，可以調整隊伍一直重打。
  打贏後結算面板的「下一關」就是直接再打下一波。
- **強度**：1～10 級，主線打到第幾章就是第幾級（大約是那一章第 4 關的難度）。陣容是鼠老大加 3～4 隻小弟。
- **寶物**：打贏除了固定的糧草與骨頭幣（和那一章頭目關一樣），再抽 5 樣隨機寶物，第一樣一定是裝備：
  糧草、骨頭幣、經驗零食、裝備、角色碎片（自己擁有的角色裡隨機一隻）。同樣的東西會合併顯示。
- 汪國和喵國都會遇到同一群老鼠。打贏照樣有城主經驗與陣營積分。

## 長相（可愛版）

圓圓的大耳朵、粉紅鼻子、兩顆門牙、細長的粉紅尾巴。「刺青」是像貼紙一樣的小圖案：愛心、星星、小魚骨、船錨。

| 名字 | 打法 | 特徵 |
| --- | --- | --- |
| 小弟／飛毛腿／搗蛋鬼 | 小卒／先鋒／搗蛋鬼 | 身上愛心、臉上星星 |
| 胖墩 | 盾兵 | 胖胖的、藍頭巾、船錨 |
| 彈弓手／起司師傅 | 投石手／藥師 | 背著彈弓、小魚骨 |
| 打手 | 精銳 | 大塊頭、紅頭巾 |
| 鼠老大阿刺 | 頭目 | 墨鏡、金項鍊、一顆金門牙 |

- `src/data/rats.ts`：關卡 `rat-1`～`rat-10`、兵種、頭目。
- `src/logic/ratRaid.ts`：時段、波數、強度、抽寶物、存檔檢查。存檔 `GameState.rats = { day, wins, total }`，出征紀錄多 `loot`。
- `src/scenes/RatScene.ts`：活動畫面。老鼠畫在 `src/scenes/components/breedArt.ts`（`ratArt`）。
- 測試：`src/logic/ratRaid.test.ts`、`tests/e2e/rats.spec.ts`。
