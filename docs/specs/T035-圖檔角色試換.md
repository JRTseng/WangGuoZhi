# T035 圖檔角色試換（先換一隻貓）

## 為什麼
Jimmy（2026-11-17）覺得遊戲裡角色與圖示用程式畫的品質不夠好，想改用 AI 繪圖工具產的圖。
先拿一隻貓試：讓他在遊戲裡實際看到新圖的效果，再決定要不要全面換。

## 做了什麼
- 素材：Jimmy 提供的英國短毛貓（立體公仔質感、正面站姿、琥珀色眼睛、藍上衣金鈴鐺）。
  去背（rembg，模型 isnet-general-use）、裁切、縮小壓縮成兩張 webp：全身 373×640、頭像 256×256，
  放在 `src/assets/photo/`。處理腳本 `scripts/make-photo-art.py`。
- 對象：喵國的「藍爵」（英國短毛貓，SR）。其他角色照舊。
- 結構：`src/scenes/components/photoArt.ts` 的 `PHOTO_ART`（鍵是角色 id）。有登記的角色用圖檔，
  沒有的照舊用程式畫。各畫面把角色 id 傳給 `drawDogHead` 的 `photo`、`DogSprite` 的 `photo`。
  - 頭像：另外一個圖片物件，緊跟在原本那張畫布（Graphics）後面，位置縮放透明度都跟著它。
  - 全身：整隻一張圖，不拍成像素（不套像素化）；主頁會跟著時段染一點光線顏色。
  - 動作全部用程式做：呼吸、跳、壓扁（坐、睡）、整隻搖晃（代替搖尾巴、轉頭）、大絕招的衝、轉、翻。
- 試看：網址加 `?try=lanjue` 直接拿到藍爵、放到主頁、排進隊伍第一位；`?photo=0` 關掉圖檔（新舊對照）。

## 還沒做／限制
- 衣服、褲子、鞋子、手套是照側身狗畫的，對不上正面站姿，圖檔角色身上先不畫（數值照算）。
  頭飾與受傷的 OK 繃有照臉的位置畫上去，位置只求合理。
- 閉眼（睡覺）、兇臉（頭目）沒有另外的圖：睡覺只有壓扁加 Z z z。
- 敵人的「肉墊兵」也是英國短毛貓，仍是程式畫法（只換了藍爵這一隻角色）。
- 圖是 AI 工具產的，正式採用前要確認授權（能不能商用）。
