# T044 「我的家」摸摸與送零食

## 目標
住在「我的家」的角色不只是走來走去給人看：點一下就能摸摸牠、送牠零食，好感度跟著增加。讓「我的家」每天都有理由進來，也讓好感度不必只靠主頁那一隻。

待辦只剩要等 Jimmy 填項目的 T009，所以夜間先做這一項（T042 好感度的待決定 D：「要不要讓『我的家』的五隻也能摸、或做送禮物」，照建議先做起來）。

## 範圍
做：
- 在「我的家」點一下角色：
  - 摸摸牠：和主頁是同一次（每個角色一天一次 +10，05:00 換日），頭上冒愛心與一句話；今天摸過了再點只會撒嬌
  - 牠會停下來看你，腳下亮一圈，畫面下面跳出互動卡：名字、好感度進度、今天還能送幾次、三種零食的按鈕、關掉
- 送零食：按互動卡上的零食，扣一個、加好感度：小肉乾 +5、香烤肉排 +12、大骨頭 +30；每個角色一天最多收 3 次
- 升級的禮物照 T042 當場自動入袋，畫面上方跳提示
- 不能送的時候（沒有那種零食、今天滿三次、好感度滿了）按鈕變灰，按了會說原因
- 點別隻角色換成牠；點空地、按 ✕、開住戶／家具／風格視窗都會關掉互動卡，角色繼續去玩
- 角色站在家具前面或上面時，點到的是角色；家具照舊可以拖
- 存檔 `bond` 多一個 `gifted`（今天每個角色收了幾次），舊存檔讀進來是空的

不做：
- 送家具、裝備或其他東西；每個角色愛吃的不一樣
- 每個角色專屬的台詞
- 好感度影響攻防
- 任務、成就、信箱跟送零食連動

## 設計說明
- 規則都在 `src/logic/bond.ts`：`BOND_GIFT`（每種零食加多少）、`GIFT_PER_DAY`、`giftBlock`／`giftSnack`／`giftsLeft`／`giftLine`。`gifted` 和 `petted` 共用同一個 `day`，換日一起清（`bondToday`）
- 版面在 `src/logic/homeLayout.ts`：`petBox`（角色可以點的範圍，最小 44）、`petAt`（重疊時點到前面那隻）、`homeCardLayout`
- `HomeScene` 沒有把角色做成可點的物件，而是在放開手指時看「按下去的位置沒移動、而且落在某隻角色的範圍裡」，這樣不會搶走家具的拖曳
- 正在互動的角色 `until = Infinity` 留在原地，關掉互動卡後 0.7 秒繼續走
- 測試狀態：`window.__WGZ__.home.pets`（每一格更新）與 `home.card`
- 存檔結構只多一個欄位，`SAVE_VERSION` 不變
