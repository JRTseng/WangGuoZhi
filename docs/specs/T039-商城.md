# T039 商城

## 目標
主頁右上的「商城」原本點了只說「即將開放」。做完後玩家每天可以進來領一份免費禮物，並用糧草與骨頭幣換零食、角色碎片與裝備，骨頭幣有地方花。

## 範圍
做：
- 主頁「商城」按鈕與右上資源列（糧草、骨頭幣）點了進商城；今天的每日禮物還沒領，「商城」亮紅點
- 商城畫面（橫式）：三欄兩列六張商品卡，一頁放完；標題列下面寫幾點換新、身上有多少糧草與骨頭幣
- 每天當地 05:00 換一批（和體力、簽到同一個換日時間），一批六樣：
  1. 每日禮物：免費，糧草 200 × 打到第幾章，一天 1 次
  2. 零食 ×3：花糧草（小肉乾 600／香烤肉排 2,400／大骨頭 9,000），一天 3 次
  3. 零食大包 ×10：花骨頭幣（30／60／120），一天 1 次
  4. 角色碎片 ×5：自己陣營的一隻 N 或 R，骨頭幣 10／20，一天 2 次
  5. 稀有碎片 ×5：自己陣營的一隻 SR（骨頭幣 40，一天 2 次），兩成機率換成 SSR（骨頭幣 100，一天 1 次）
  6. 裝備一件：一般裝備，稀有度比重跟頭目關掉落一樣，骨頭幣 15／30／60／120，一天 1 次
- 零食的種類跟著主線章節（和過關掉的同一種）；碎片優先挑已經有的角色
- 錢不夠時按鈕變灰，點了提示「糧草不夠」「骨頭幣不夠」；買到上限顯示「今天賣完了」
- 存檔多一個欄位 `mall`（哪一天、每一格買了幾次）

不做：
- 真的付費、儲值、月卡
- 花骨頭幣「換一批」
- 專屬裝備、爬塔飾品、家具、背景上架
- 信箱（仍是「即將開放」）

## 設計說明
- 規則在 `src/logic/mall.ts`（純函式）：`mallGoods` 算今天這一批、`mallBlock` 看能不能買、`buyMall` 扣錢給東西、`mallGiftReady` 給主頁紅點、`sanitizeMall` 讀檔整理。數字都在 `MALL` 與 `MALL_LIMIT`。
- 商品不存進存檔：用「日期＋第幾格＋陣營」當亂數種子現算，所以同一天怎麼開都一樣，存檔只記 `mall.day` 與 `mall.bought`。
- 給東西沿用老鼠幫寶物的型別與 `applyRatLoot`（糧草、骨頭幣、零食、碎片、裝備）。
- 排版在 `src/logic/mallLayout.ts`，畫面在 `src/scenes/MallScene.ts`。測試用的畫面狀態在 `window.__WGZ__.mall`（`shop` 這個名字已經被補體力的小視窗用掉了）。
- 碎片的挑法：把那一格的角色照當天亂數排好，有已經擁有的就挑最前面那隻。白天抽到新角色時那一格可能換成別隻，買過的次數照舊算。
