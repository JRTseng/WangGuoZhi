# T014 狗狗裝備

（2026-11-11 晚 Jimmy 提出：狗狗擬人化，有自己的裝備與可愛裝飾。其餘細節由接手的人依 TEMPLATE 補齊後再動工，數值先暫定並列入報告。）

## 目標
每隻狗可以穿戴裝備，例如圍兜兜、衣服、褲子、尿布、受傷時的頭套，讓狗狗更擬人、更可愛，也能小幅提升能力。

## 範圍
做：
- 裝備分 5 個部位（Jimmy 指定，先這幾類）：
  - 衣服（例：圍兜兜、小背心、毛衣）
  - 手套（例：肉球手套、拳擊手套）
  - 褲子（例：短褲、尿布）
  - 鞋子（例：雨鞋、小布鞋）
  - 頭飾（例：蝴蝶結、頭巾、受傷頭套）
- 每隻狗每個部位最多穿 1 件，共 5 格。
- 裝備資料檔 `src/data/equipment.ts`：每件有 id、名稱、部位、稀有度（沿用 N／R／SR／SSR）、加成（攻擊／防禦小幅加值），名字與造型全部原創、可愛風。第一版每個部位 3 到 4 件。
- 取得方式：出征收成有機率掉落（掉落率暫定）。
- 主頁左側「倉庫」按鈕打開倉庫：列出擁有的裝備，可依部位篩選。
- 角色畫面：顯示 5 個裝備格，點格子可穿上、換下。
- 戰力計算把裝備加成算進去（攻防 = 基礎 + 升級成長 + 裝備）。
- 外觀：第一版在角色圖上疊簡單的幾何圖形或色塊表示穿了什麼（例如頭飾畫在頭上、衣服改變身體顏色），正式美術之後再補。
- 邏輯放 `src/logic/equipment.ts`（穿、脫、換、計算加成），有單元測試；狀態可直接序列化（給 T006 存檔）。

不做：
- 裝備強化、合成、套裝效果（之後再說）。
- 商城販售裝備（之後接商城任務時再做）。
- 正式美術圖。

## 驗收標準
- [ ] 每隻狗 5 個部位各最多 1 件；同一件裝備不能同時穿在兩隻狗身上
- [ ] 穿上、換下、互換後戰力正確變化（單元測試）
- [ ] 出征收成有機率掉落裝備，掉落用可注入的亂數（單元測試）
- [ ] 倉庫可依部位篩選；角色畫面可穿脫（Playwright）
- [ ] 截圖：倉庫、角色裝備畫面、穿上裝備的狗狗（直式、橫式）
- [ ] `npm run lint`、`npm test`、`npm run build`、`npm run shot` 全綠
