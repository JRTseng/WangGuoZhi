# T016 自創背景與音樂

## 目標
每一章與主頁都有自己的細緻場景，不再是換顏色的同一張圖；遊戲有背景音樂與音效，設定裡的開關真的有作用。背景、音樂、音效全部用程式做出來，沒有外部檔案。

## 範圍
做：
- 背景：十章的場景（落葉坡、竹林渡、雪嶺、桃花谷、黃沙道、霧沼澤、赤焰嶺、碧海灣、雲頂棧、汪都）加上秋祭燈會與主城，共 12 張，每張有自己的遠景、中景、地面與會動的小東西（飄落物、霧、螢火蟲、浪、燈籠等）。全部用 Phaser 的繪圖功能畫，不放圖檔。
- 主頁背景：原本只能換 4 張，改成每打倒一章的 Boss 就多一張，共 12 張（十章、燈會活動、主城）。照原本的規則：打倒第 N 章 Boss 拿到下一章的場景，打倒最後一章的 Boss 送主城「凱旋歸城」。
- 音樂：主頁與戰鬥各一首短循環，用 Web Audio 合成（撥弦、笛聲、低音、鼓）。主頁那首在主頁、組隊、訓練、召募、倉庫、地圖、劇情都播；進戰鬥換成戰鬥那首。
- 音效：點按、攻擊、爆擊、補血、大絕招、倒下、勝利、落敗、升級、召募、抽到稀有、穿裝備。一樣用 Web Audio 合成。
- 設定：「音樂」開關接上音樂；新增「音效」開關管音效。兩個都存檔。
- 授權：`docs/LICENSE-ASSETS.md` 寫明背景、音樂、音效都是本專案原創、用程式產生。

不做：
- 背景圖鑑畫面（主頁的「背景」按鈕照舊輪流換）
- 每一章各自的音樂、Boss 專屬音樂
- 語音（維持 T017 留的掛點）
- 音量滑桿（只有開關）
- 戰鬥畫面的狗畫上裝備（T014 留下來的事）

## 驗收標準
- [ ] 12 個場景各有自己的畫法，沒有任何一張借用別張的近景
- [ ] 打倒第 N 章 Boss 後，主頁「背景」按鈕多一張可以換（下一章的場景，最後一章是主城）；舊存檔選過的背景不變
- [ ] 第一次點畫面後開始播音樂（瀏覽器規定要先有操作才能出聲）；進戰鬥換曲、回主頁換回來
- [ ] 設定關掉「音樂」馬上靜音，再打開會接著播；「音效」同理；重開遊戲後開關還在
- [ ] 切到別的分頁或鎖螢幕時不出聲
- [ ] 低畫質時場景裡會動的東西都關掉
- [ ] 所有新增邏輯有單元測試，`npm test` 全綠
- [ ] 相關畫面有 Playwright 截圖，附在 PR
- [ ] 手機橫放可正常顯示（遊戲已固定橫向）
- [ ] 實際聽起來好不好聽、音量合不合適：待 Jimmy 手機實測

## 設計說明
- 樂譜是資料：`src/logic/music.ts` 用一行字串記一個聲部（例如 `D4:1 E4:0.5 -:0.5`），純函式把它換成「第幾秒、什麼音高、多長」的清單，並算出某一段時間內該排哪些音（循環接縫也在這裡處理）。有單元測試檢查每個聲部長度一致。
- 音效也是資料：`src/logic/sfx.ts` 每個音效是幾個「波形、起訖頻率、長度、音量」的小段。
- 真正出聲在 `src/scenes/components/audio.ts`：一個 AudioContext，音樂與音效各走一條音量線；每 50 毫秒把接下來 0.25 秒的音排進去；換曲時舊的淡出、新的接上；每次排程時讀設定，所以開關馬上生效。
- 哪個畫面播哪首由 `musicForScene` 決定，在 `main.ts` 統一掛到每個場景的 create 事件，各場景不用自己管。
- 背景：`Scenery` 的建構參數不變，四個用到它的畫面不用改。山稜線、顏色混合這類計算放 `src/logic/sceneryShapes.ts`（固定種子，每次畫出來都一樣，截圖才穩定）；每個場景的畫法在 `src/scenes/components/sceneryArt.ts`。
- 存檔：`settings.sfx` 是新欄位，舊存檔沒有就補 `true`；`backgroundId` 可以是任何一章的場景。不用升 `SAVE_VERSION`。
