# T040 信箱

## 目標
主頁右上的「信箱」是最後一顆點了只說「即將開放」的按鈕。做完後玩家可以進信箱收信、領附件；打倒頭目、升官、每個星期都會收到信，之後遊戲更新的消息也有地方寄。

## 範圍
做：
- 主頁「信箱」點了進信箱；有信還沒看、或附件還沒領，「信箱」亮紅點
- 信箱畫面（橫式）：左邊是信的清單（一頁五封，超過可以換頁），右邊是打開的那封信（標題、寄件人、內文、附件），最下面一排按鈕「領取附件」「刪除」「全部領取」「清掉看過的」
- 遊戲是單機的，沒有伺服器寄信，信照規則產生：
  1. 歡迎信：一開始就有，骨頭幣 100、小肉乾 ×5
  2. 捷報：每打倒一章的頭目一封，糧草 300 × 第幾章、骨頭幣 20 + 10 × 第幾章
  3. 升官賀信：城主等級到 10／20／30／40／50／60 各一封，骨頭幣 50 + 5 × 等級、香烤肉排 ×（等級 ÷ 10）
  4. 每週補給：每個星期一 05:00 換新的一封，糧草 500 × 打到第幾章、骨頭幣 30、零食 ×3（種類跟著章節）；上週沒領的就過期
  5. 更新消息：遊戲有新東西時寄一封（清單 `MAIL_NEWS`，之後更新就往下加）；這次先寄一封「驛站開張了」，骨頭幣 50
- 還沒領附件的信排最前面，再來是還沒看的；在信箱裡看信、領附件時清單不重排
- 附件還沒領的信不能刪；刪掉的信不會再出現
- 舊存檔進來會一次收到之前已經達成的捷報與賀信
- 加入喵國時信裡的說法跟著換（汪國 → 喵國、狗狗 → 貓咪）
- 存檔多一個欄位 `mail`（哪幾封看過、領過、刪掉）

不做：
- 帳號、伺服器、推播、玩家之間寄信
- 信的到期時間（除了每週補給）
- 附件送角色或專屬裝備
- 把現有的獎勵（積分戰、圖鑑、任務）改成用信箱發

## 設計說明
- 規則在 `src/logic/mail.ts`（純函式）：`inbox` 算現在有哪些信、`readMail`／`claimMail`／`claimAllMail`／`deleteMail`／`deleteDoneMail` 改存檔、`mailPending` 給主頁紅點、`sanitizeMail` 讀檔整理。數字都在 `MAIL`。
- 信的內容不存進存檔，每次照進度現算；存檔只記信的 id。每週補給的 id 是 `week-那週星期一的日期`，過期的 id 會自動清掉。
- 附件沿用老鼠幫寶物的型別與 `applyRatLoot`。
- 排版在 `src/logic/mailLayout.ts`，畫面在 `src/scenes/MailScene.ts`，測試用的畫面狀態在 `window.__WGZ__.mail`。
- 之後要寄更新消息：在 `MAIL_NEWS` 加一筆（id 用 `news-` 開頭、不要重複），玩家下次開遊戲就會收到。
