# T011 任務模式

## 目標
主頁「任務」打開後有主線、每日、成就三種任務，做完領糧草與骨頭幣；有獎勵可領時主頁「任務」亮紅點。

## 範圍
做：
- 主線任務：跟著章節走，每章兩個（打到第 3 關、打倒頭目），十章共 20 個。
- 每日任務：出征 3 次、打贏 2 場、專項特訓 3 次、召募 1 次，加一個「完成 3 個每日任務」；每天 05:00 重新開始。
- 成就：累計出征、累計打贏、狗狗數量、累計召募、升星、特訓、裝備種類、最高等級，各有 4～6 段。
- 任務畫面（橫式）：左邊分頁與「全部領取」，右邊兩欄任務卡；完成按「領取」，沒完成的主線與每日按「前往」。
- 主頁「任務」按鈕接上、有獎勵時亮紅點。
- 存檔：`GameState.quests`，`sanitizeState` 有檢查。

不做：
- 任務送狗、碎片、裝備（目前只送糧草與骨頭幣）。
- 每週任務、活動任務、任務劇情對話。
- 推播提醒。

## 驗收標準
- [x] 主線進度跟著通關紀錄，完成才能領，領過不能再領
- [x] 每日次數在出征結算、特訓、召募時自動加，換日清空
- [x] 成就領完一段換下一段，不能跳著領
- [x] 「全部領取」一次領完所有分頁，連續達成的幾段成就一起領
- [x] 主頁紅點跟著「有沒有獎勵可領」亮與熄
- [x] 舊存檔沒有任務欄位也讀得進來
- [x] 所有新增邏輯有單元測試，`npm test` 全綠
- [x] 相關畫面有 Playwright 截圖，附在 PR

## 設計說明
- 邏輯 `src/logic/quests.ts`（純函式）、排版 `src/logic/questLayout.ts`、畫面 `src/scenes/QuestScene.ts`。
- 主線與成就的進度都是從別的欄位算出來的（`cleared`、`owned`、`gacha.pulls`、`nextExpeditionNo`、狗的星數與特訓次數、`gear`），
  所以存檔只記「領過哪些」（`quests.claimed`）與累計勝場（`quests.wins`）。舊存檔一打開，已經達成的直接可以領；
  累計勝場以前沒記，用「通過了幾關」起算。
- 每日任務的次數放在 `quests.daily.counts`，跟著 `daily.day`（T019 的 05:00 換日）在 `settle` 裡一起清空。
- 出征與打贏在 `settleBattle` 裡記（自動出征、略過戰鬥也算）；特訓與召募在各自的畫面呼叫 `countQuest`。十連算 10 次召募。
- 主線獎勵 = 那一關的過關獎勵（等於第一次通過多拿一份）；每日的糧草獎勵乘上目前打到第幾章，後面才不會沒感覺。
- 成就第 n 段獎勵：糧草 500 × n、骨頭幣 20 × n。
- 「完成 3 個每日任務」只要 4 個裡的 3 個，特訓全部練滿的人也拿得到。
- 進任務畫面會先開有獎勵可領的分頁。

## 任務清單
主線（20 個）：第 N 章通過第 3 關、第 N 章打倒頭目。

每日：
| 任務 | 獎勵 |
| --- | --- |
| 出征 3 次 | 糧草 300 × 章數 |
| 打贏 2 場 | 糧草 300 × 章數 |
| 專項特訓 3 次 | 糧草 200 × 章數 |
| 召募 1 次 | 骨頭幣 10 |
| 完成 3 個每日任務 | 骨頭幣 30 |

成就：
| 成就 | 各段目標 |
| --- | --- |
| 累計出征 | 10／50／150／400／1000 次 |
| 累計打贏 | 10／50／150／400／1000 場 |
| 擁有狗狗 | 8／12／16／20／25／30 隻 |
| 累計召募 | 10／50／100／300 次 |
| 狗狗升星合計 | 1／5／15／30 次 |
| 專項特訓合計 | 10／50／150／300 次 |
| 收集裝備 | 5／10／20／30 種 |
| 有狗狗升到 | 10／20／40／60／80／100 級 |

## 需要 Jimmy 決定的事
- 任務內容、目標數字與獎勵都是暫定，要不要調。
- 召募現在免費，所以「召募 1 次」等於每天白拿 10 骨頭幣、召募成就也很好拿；等召募接上骨頭幣時要一起調。
- 體力現在是無限，「出征 3 次」「打贏 2 場」很快就做完；體力調回來後剛好是一天的份量。
- 任務要不要送別的東西（碎片、裝備、狗狗）。
- 要不要加每週任務。
