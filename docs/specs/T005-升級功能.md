# T005 升級功能

（2026-11-11 白天先寫下 Jimmy 指定的升級規則，其餘部分由接手的人依 TEMPLATE 補齊後再動工）

## 目標
狗狗靠出征累積經驗值升級（Jimmy 2026-11-11 指定），等級上限 100，每升一級攻擊、防禦都會成長。成長由「固定值 + 小幅隨機」組成，讓每隻狗養起來有點不一樣，但不會破壞平衡。

## 範圍
做：
- 經驗值與升級（Jimmy 2026-11-11 指定）：
  - 每隻狗有經驗值 `exp`。出征收成時，隊伍裡每隻狗都拿到經驗值（依關卡難度／耗時給，數值暫定；T004 做完後打輸也拿一部分，暫定一半）。
  - 經驗值滿了就自動升級，一次收成可能連升好幾級，多出來的經驗值留到下一級。
  - 每級所需經驗值隨等級遞增（曲線暫定，例如 `需求 = 基礎 × 等級^1.5`），目標是前期升得快、後期慢。
  - 等級上限 100；滿級後經驗值不再累積。
  - 收成結算畫面顯示每隻狗拿到多少經驗、有沒有升級、升級的成長值。
  - 角色畫面顯示等級與經驗條。
  - 之後（不在本任務）可再加「花資源直接給經驗」的道具，本任務不做。
- 每級成長（Jimmy 2026-11-11 指定並確認數值）：
  - 固定成長：依定位，主屬性 +3、副屬性 +2
    - 前排（突擊／守護）：突擊攻擊為主，守護防禦為主
    - 後排（謀略／幸運）、隊長（補給）：攻防各 +2.5，四捨五入後輪流給 +3／+2
  - 隨機加成：攻擊、防禦各自再加 0、+1 或 +2（平均 +1）
  - 每次升級結果要顯示，例如「攻擊 +3（+1）」，讓玩家看得到這次運氣好不好
- 防止極端值：同一隻狗累積的隨機加成，和平均值（每級 +1）的差距不得超過 ±4。超過時，下一次的隨機值改往平均拉回。
- 不能刷：升級時就把隨機結果寫進狀態，存檔讀檔或重開都不會重抽（隨機要可注入，方便測試）。

不做：
- 升星、碎片（屬於 T007）。
- 花資源升級或經驗道具（之後再說）。

## 驗收標準

- [ ] 跑 1000 次模擬，任何一隻狗累積的隨機加成和平均值的差距都在 ±4 內
- [ ] 同一個亂數種子會得到同樣的結果；升級結果存在狀態裡
- [ ] 收成後隊伍每隻狗都拿到經驗值；經驗滿了自動升級、可連升、多的經驗保留
- [ ] 等級到 100 就不再升級、經驗不再累積
- [ ] 所有新增邏輯有單元測試，`npm test` 全綠
- [ ] 升級畫面有 Playwright 截圖（直式、橫式）

## 設計說明
- 平衡估算：上限改 100 級後，固定成長約 +495（攻防合計），隨機成長平均 +198、上下最多差 8，隨機對戰力的影響約 ±1%，不會蓋過等級和稀有度的差距。
