# T005 升級功能

（2026-11-11 白天先寫下 Jimmy 指定的升級規則，其餘部分由接手的人依 TEMPLATE 補齊後再動工）

## 目標
狗狗可以花資源升級，每升一級攻擊、防禦都會成長。成長由「固定值 + 小幅隨機」組成，讓每隻狗養起來有點不一樣，但不會破壞平衡。

## 範圍
做：
- 升級：消耗糧草（與骨頭幣，數值待定），等級 +1，上限暫定 30。
- 每級成長（Jimmy 2026-11-11 指定並確認數值）：
  - 固定成長：依定位，主屬性 +3、副屬性 +2
    - 前排（突擊／守護）：突擊攻擊為主，守護防禦為主
    - 後排（謀略／幸運）、隊長（補給）：攻防各 +2.5，四捨五入後輪流給 +3／+2
  - 隨機加成：攻擊、防禦各自再加 0、+1 或 +2（平均 +1）
  - 每次升級結果要顯示，例如「攻擊 +3（+1）」，讓玩家看得到這次運氣好不好
- 防止極端值：同一隻狗累積的隨機加成，和平均值（每級 +1）的差距不得超過 ±4。超過時，下一次的隨機值改往平均拉回。
- 不能刷：升級時就把隨機結果寫進狀態，存檔讀檔或重開都不會重抽（隨機要可注入，方便測試）。

不做：
- 升星、碎片（屬於 T007）。

## 驗收標準
- [ ] 固定成長正確，隨機值都落在 0 到 +2 之間
- [ ] 跑 1000 次模擬，任何一隻狗累積的隨機加成和平均值的差距都在 ±4 內
- [ ] 同一個亂數種子會得到同樣的結果；升級結果存在狀態裡
- [ ] 資源不足時不能升級，狀態不變
- [ ] 所有新增邏輯有單元測試，`npm test` 全綠
- [ ] 升級畫面有 Playwright 截圖（直式、橫式）

## 設計說明
- 平衡估算：以 30 級為例，固定成長約 +145（攻防合計），隨機成長平均 +58、上下最多差 8，對戰力的影響約 ±3%，不會蓋過等級和稀有度的差距。
- 戰力公式維持 T002 的版本，但攻防改用「基礎值 + 成長值」計算。
