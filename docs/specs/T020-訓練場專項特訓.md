# T020 訓練場專項特訓

（2026-11-12 白天由 Jimmy 在「規劃訓練場可做的事」討論串選定方向，數值都是暫定）

## 目標
訓練場現在只能看等級與成長，沒有可以操作的東西。做完後玩家可以花糧草替狗狗做攻擊或防禦特訓，永久小幅提高屬性，糧草也有了用途。

## 範圍
做：
- 訓練場每張狗狗卡片加兩個按鈕：「攻擊特訓」「防禦特訓」。
- 每按一次，該屬性永久 +1，並扣糧草。
- 每隻狗攻擊、防禦各自最多特訓 10 次（各 +10），滿了按鈕變灰並顯示「已滿」。
- 花費隨次數遞增：該屬性第 n 次特訓花 `100 × n` 糧草（第 1 次 100，第 10 次 1000；單一屬性練滿共 5500，一隻狗攻防都練滿共 11000）。
- 糧草不夠時按鈕變灰，顯示還差多少。
- 卡片上顯示特訓進度，例如「攻擊特訓 3/10」，按鈕上顯示下一次的花費。
- 特訓成功有簡單回饋（數字跳動或「攻擊 +1」飄字），戰力同步更新。
- 特訓加成算進攻擊、防禦與戰力，戰鬥、選狗、主頁顯示的數值都一致。
- 特訓次數存進存檔（跟著 T006 的存檔格式，舊存檔沒有這個欄位時當成 0）。
- 訓練場上方的說明文字補一句特訓的說明。

不做：
- 不給經驗、不加等級（Jimmy 2026-11-12 已決定不做「糧草換經驗」，升級速度由體力控制）。
- 不用骨頭幣買特訓。
- 不能退回或重置特訓。
- 板凳寄宿（T021）、升星（T007）、技能訓練（T017）、小遊戲（T022）。

## 驗收標準
- [ ] 特訓一次，該屬性 +1、糧草扣掉正確金額、次數 +1
- [ ] 第 n 次花費等於 100 × n；攻擊與防禦的次數分開計算
- [ ] 第 10 次之後不能再特訓；糧草不夠時不能特訓，狀態不變
- [ ] 特訓加成反映在 `dogStats`、戰力與戰鬥用的隊伍數值
- [ ] 存檔後重開，特訓次數與屬性都還在；沒有這個欄位的舊存檔可正常讀取
- [ ] 所有新增邏輯有單元測試，`npm test` 全綠
- [ ] 訓練場有 Playwright 截圖（直式、橫式；含可按、糧草不足、已滿三種狀態），附在 PR
- [ ] 手機直式瀏覽器可正常顯示，按鈕好按（高度至少 44px）

## 設計說明
- 邏輯放 `src/logic/training.ts`（純函式）：`drillCost(count)`、`canDrill(progress, stat, food)`、`applyDrill(...)`。上限與單價做成常數，方便之後調整。
- 養成進度 `GameState.dogs` 每隻狗加 `drill: { attack: number; defense: number }`，`dogStats` 把它加進攻防。
- 平衡估算：一隻狗練滿是攻防合計 +20，約等於 4 級的固定成長，夠有感但不會蓋過等級。目前打到第 3 章 Boss 約 33 次出征，糧草收入大約 2 萬，足夠把主力一兩隻練滿、其他練一半，玩家得挑要先練誰。
- 關卡建議戰力先不動；做完後用模擬確認前 3 章的勝率沒有偏太多，結果寫進報告。
- 卡片變高後 5 隻狗在直式畫面可能放不下，訓練場要能捲動（T007 加狗之後也需要）。
