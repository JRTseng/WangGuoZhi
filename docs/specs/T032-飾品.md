# T032 飾品：裝備欄多兩格，爬塔限定裝備改成看得到的飾品

Jimmy 2026-11-17：「爬塔掉落的裝備要加上特殊的一些真實世界會出現的飾品外觀嗎？例如鈴鐺，蝴蝶結或者等等，
可以把角色的裝備欄多一些飾品位置」。

## 做了什麼

- **裝備欄多兩格飾品**：頸飾、耳飾。不佔原本的五個部位（衣服、手套、褲子、鞋子、頭飾），帽子和飾品可以一起戴。
- **爬塔限定的五件改成飾品**：樣子是真實世界看得到的小東西，戴上去角色身上看得到（全身像與小頭像都有）。
  攻防與特殊功能和原本一樣，貓狗都能戴。
- **倉庫畫面**：飾品兩格直的排在角色右邊；右邊多一個「飾品」分頁。「一鍵穿上」也會幫忙戴飾品。
- **舊存檔**：id 沿用 `tw-N`，已經拿到的不用重拿；原本穿在頭、手、腳上的那幾件讀檔時自動搬到飾品格
  （那一格已經有東西就放回倉庫）。

## 程式

- `src/data/equipment.ts`：`GearSlot` 多 `neck`、`ear`；`BASE_SLOTS`（五個部位）、`ACCESSORY_SLOTS`（兩格飾品）、
  `GEAR_SLOTS` 是兩者合起來。樣式多 `bell`／`scarf`／`locket`／`ribbon`／`flower`。
- `src/scenes/components/gearArt.ts`：`drawAccessories` 畫在頭的前面（頸飾在下巴下面、耳飾在耳朵旁邊）。
- `src/logic/equipment.ts` 的 `sanitizeGear`：爬塔裝備換了位置時搬過去。
- `src/logic/gearLayout.ts`：七個格子、七個分頁。

## 待 Jimmy 看

- 款式與名字；飾品要幾格（現在兩格）。
- 之後要不要讓關卡或活動也掉一般的飾品（現在只有爬塔的五件）。
- 戰鬥畫面的小頭像比較小，飾品看得到但不明顯。
