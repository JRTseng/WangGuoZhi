## 目標
戰鬥中狗狗會放大絕招：有動畫、喊出招式名、帶一句玩家可以自己填的台詞，讓人想看完整場。勝負與數值完全不變。

## 範圍
做：
- 大絕招演出：壓暗 → 斜的字卡滑進來（大頭、名字、招式名）→ 台詞字幕 → 字卡滑走 → 依種類播特效 → 傷害數字放大。
- 五種特效，對應 T023 的出手種類：單體（幸運、Boss）、穿透（突擊）、整排（謀略）、補血（補血）、強化（補給、守護）。
- 播放時機（暫定）：每隻狗出手 2 次集滿 EN 條，第 3 次出手播成大絕招，放完歸零。補血狗只在真的補血那一下放。章末 Boss 也會放，野犬不會。
- 血條下面的 EN 條（集氣中藍色，滿了金色）。現在只照出手次數顯示，T023 接上真正的 EN 值。
- 訓練場每張卡片的「改台詞」：開打字視窗，最多 16 個字；留空或「恢復預設」用回預設台詞。進存檔。
- 19 隻狗各一句預設台詞、3 個 Boss 的招式名與台詞。
- 語音包掛點：放招時算出提示 id（例如 `daer.ultimate`）問語音包有沒有音檔，目前沒有語音包所以不出聲。

不做：
- 技能的真正效果、EN 值的真正規則、玩家點狗放招、陣型（T023）。
- 語音合成與語音包內容。
- 技能升級。
- 一般攻擊的新動畫。

## 設計說明
- `src/logic/skillShow.ts`（純函式）：`planShow(events, casters)` 從現有的戰鬥紀錄排出「哪幾下是大絕招、EN 條到哪」，回傳和紀錄一一對應的陣列；不改紀錄本身。另有演出長度 `ultDelayMs`、台詞整理 `cleanSkillLine`／`setSkillLine`。
- `src/scenes/components/UltimateShow.ts`：一次大絕招的全部動畫，只吃位置、外觀、種類與文字，不知道戰鬥規則。T023 換掉勝負規則後可以直接沿用，只要改成從真正的紀錄告訴它「這一下是什麼種類、打到誰」。
- `src/scenes/BattleScene.ts`：遇到大絕招就先播字卡，字卡滑走才套用那一下的扣血；略過時照舊把剩下的紀錄一次套完。
- `src/scenes/components/TextPrompt.ts`：Phaser 畫布叫不出手機鍵盤與中文輸入法，所以打字用一般網頁輸入框蓋在遊戲上面。之後取名字之類的也可以用。
- `src/logic/voicePack.ts` + `src/scenes/components/voice.ts`：語音包掛點。之後做語音包，在 `VOICE_PACKS` 加資料（提示 id → 音檔）並加一個選語音包的設定即可。
- 存檔：`GameState.skillLines`（狗狗 id → 台詞），`sanitizeState` 已補檢查，SAVE_VERSION 不變。
- 測試模式 `?fast=1` 不播演出動畫（只算時間），所以其他畫面測試的速度不受影響；想在測試模式看動畫用 `?fast=1&battle=normal`。
