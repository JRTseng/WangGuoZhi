# T029 貓族與選陣營

Jimmy 2026-11-17：「使用者一開始可以選擇要加入哪個陣營」「兩個陣營招募內容不同角色」「費用的部分都不用考慮，單純先以單機為主」。
（之後 T031 把貓補到 50 種，並給喵國自己的劇情與敵人，見 `T031-喵國補完.md`。）
聊天先不做；每週積分戰是下一項（單機，對面陣營的分數由遊戲模擬）。

## 做了什麼

- **兩個陣營**：汪國（狗）、喵國（貓）。記在存檔的 `faction`（`'dog'`／`'cat'`／空字串是還沒選）。
- **選陣營畫面**（`FactionScene`）：還沒選的存檔一進主頁就會被帶來，左右兩張大卡，各有代表角色、一開始的五隻、召募內容與「加入」按鈕。
  選過以後從主頁帳號卡旁邊的陣營徽章進來，可以換。
- **喵國 20 隻貓**（`src/data/cats.ts`）：N 6／R 6／SR 4／SSR 4，六種定位都有，定位與專屬打法和狗共用同一套規則。
  SR、SSR 八隻各有一件專屬裝備（抽到就送），每隻都有大絕招台詞與姿勢。
- **貓的畫法**：沿用照品種畫的特徵表，多了貓專用的粉紅小鼻子、鬍鬚、直的瞳孔、摺耳、虎斑／三花花紋、細長與蓬鬆兩種貓尾巴。20 個品種各一份特徵。
- **召募分陣營**：汪國只抽得到狗（50 種）、喵國只抽得到貓（20 種）；圖鑑總數、看板主打、簽到第 7 天自選 SSR 都跟著陣營。
- **組隊名單**：看得到自己陣營的全部，加上手上已經有的別陣營角色。

## 規則（`src/logic/faction.ts`）

| 情況 | 結果 |
| --- | --- |
| 還沒選 | 當成汪國，遊戲照常能玩；主頁會帶去選 |
| 還沒開始玩（沒出征、沒抽過）就選或換 | 手上直接換成那個陣營的五隻，隊伍與主頁角色一起換 |
| 已經玩過才換 | 原本的夥伴、裝備、進度全部留著，另外送新陣營的五隻；之後召募到的是新陣營的角色 |

一開始的五隻：汪國 大耳、黑旋、長鬚、小算、阿白；喵國 橘座、虎紋、墨領、小滿、雪糰。

## 測試用網址

- `?faction=cat`／`?faction=dog`：直接指定陣營。
- `?faction=0`：還沒選也不要自動跳去選陣營畫面（畫面測試預設）。
