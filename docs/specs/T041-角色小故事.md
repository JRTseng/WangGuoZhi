# T041 角色小故事

## 目標
100 個角色每一個都有自己的小故事、喜歡的東西、害怕的東西。在圖鑑點角色就看得到，拿到這個角色才會揭曉，讓收集多一點期待。

待辦只剩要等 Jimmy 填項目的 T009，所以夜間先做這一項（T038 圖鑑的「需要 Jimmy 決定的事」裡提過要不要加角色小故事；這一項只加文字、不動數值，之後要改內容只改一個資料檔）。

## 範圍
做：
- `src/data/bios.ts`：汪國 50 隻、喵國 50 隻，每隻一段小故事（最多 72 字）、喜歡、害怕（各最多 18 字），全部原創
- 角色資料視窗（圖鑑、組隊、出征選隊伍長按共用的那一個）右半邊變成兩頁：「成長技能」與「小故事」，右上角一顆按鈕換頁
- 小故事那一頁：小故事、喜歡、害怕、口頭禪（沿用大絕招的預設台詞）
- 還沒有的角色：小故事那一頁只顯示「？？？」與「拿到這位夥伴以後，就能看牠的小故事」
- 從圖鑑打開先看小故事（換過頁會記著）；從組隊、出征打開照舊先看成長技能

不做：
- 讓玩家自己改小故事
- 看完小故事的獎勵、「新故事」紅點
- 敵人與頭目的小故事、背景圖鑑、裝備圖鑑
- 不動任何數值與存檔格式

## 設計說明
- 純資料在 `src/data/bios.ts`（`BIOS`、`bioOf`、字數上限 `BIO_LIMITS`），`src/data/bios.test.ts` 檢查每個角色都有、字數不超過。之後加新角色沒補故事，測試會提醒。
- 畫面改在 `src/scenes/components/DogInfoPanel.ts`：右半邊畫在一個容器裡，換頁時重畫；選項 `tab` 決定一開始哪一頁、`onTab` 通知場景。
- 故事裡的「狗」「貓」是照角色寫的，不經過 `wt()` 換字（加入喵國以後看汪國的狗，故事裡還是狗）。
