# T001 專案骨架

## 目標
建立可建置、可測試、可自動部署的專案基礎，瀏覽器打開能看到一個直式空畫面與版本號。

## 範圍
做：
- Vite + TypeScript + Phaser 3 專案初始化
- 直式畫面設定（基準 390 x 844，等比縮放置中）
- 一個 `BootScene` 顯示「汪國志」文字與 build 版本號
- Vitest 設定與一個範例測試
- Playwright 設定與一個截圖測試（輸出到 `artifacts/screenshots/`）
- GitHub Actions：push 與 PR 時執行 lint、test、build、截圖；main 分支成功後部署到 GitHub Pages
- `npm run dev`、`npm test`、`npm run build`、`npm run shot` 四個指令
- ESLint + Prettier 基本設定

不做：
- 任何遊戲邏輯
- 美術資源

## 驗收標準
- [ ] `npm install && npm run build` 成功
- [ ] `npm test` 全綠
- [ ] `npm run shot` 產出至少一張截圖
- [ ] PR 上的 CI 全綠，並附截圖
- [ ] GitHub Pages 連結可在手機瀏覽器開啟，看到直式畫面與版本號

## 設計說明
- 畫面尺寸以 390 x 844 為設計基準，使用 Phaser 的 `Scale.FIT` 加 `CENTER_BOTH`。
- 版本號由 `package.json` 的 version 加上 git short hash 組成，在 build 時注入。
- 截圖測試以 headless Chromium 模擬 iPhone 尺寸。

## 禁止事項
- 不加任何 UI 框架（React、Vue 等），畫面全部由 Phaser 處理
- 不加狀態管理套件
