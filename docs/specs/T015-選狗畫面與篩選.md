# T015 選狗畫面與篩選

（2026-11-11 晚 Jimmy 提出。隊伍上限已在 T004 改成 5 隻；狗狗之後會因抽卡變多，選狗畫面要好找。細節由接手的人依 TEMPLATE 補齊後再動工。）

## 目標
組隊與出征選狗時，狗狗很多也能快速找到想要的，組出自己的夢幻隊伍。

## 範圍
做：
- 組隊畫面與出征選狗畫面改版：上方 5 個隊伍格，下方可捲動的狗狗卡片格（直式、橫式都要好點）。
- 篩選列，預設「全部（All）」，可依：
  - 定位（突擊／守護／謀略／幸運／補給）
  - 稀有度（N／R／SR／SSR，T007 之後才有資料，先預留）
  - 體型（小型／中型／大型）、屬性（T007 定義後接上，先預留）
  - 狀態（可出征／出征中）
- 排序：戰力高到低（預設）、等級、稀有度。
- 一鍵「自動編隊」：挑可出征中戰力最高的 5 隻。
- 篩選與排序邏輯放 `src/logic/`，有單元測試。

不做：
- 抽卡（T007）、新增犬種資料（T007）。

## 驗收標準

- [x] 截圖：組隊畫面、出征選狗畫面（直式、橫式）、套用篩選後

## 實作紀錄（2026-11-12）
- 組隊編排與出征選狗共用同一個選狗元件 `src/scenes/components/DogPicker.ts`；篩選、排序、自動編隊在 `src/logic/dogFilter.ts`，排版與捲動範圍在 `src/logic/pickerLayout.ts`。
- 篩選列目前有「定位」與「狀態」兩排，條件可以疊加；排序按鈕輪流切換戰力／等級。
- 稀有度、體型、屬性：`DogData` 已預留 `rarity`、`size`、`element` 欄位，篩選與稀有度排序的邏輯與單元測試都寫好了；等 T007 填上資料，稀有度排序會自動出現，篩選按鈕到時再加上畫面。
- 排序時擁有的狗一律排在未擁有的前面。
- 自動編隊：不看目前的篩選條件，直接換成可出征（擁有且沒在出征）裡戰力最高的 5 隻；沒有可出征的狗就不動。
- 隊伍滿了再點別隻維持沒反應（Jimmy 2026-11-12 確認）。
- 卡片格固定大小，放不下時上下拖曳捲動（電腦可用滾輪），右側有捲動條；拖曳後放開不算點擊。目前 8 隻狗一頁放得下，T007 加狗之後就會用到捲動。
- 出征選狗（橫式）：關卡時間與建議戰力併進標題列，出發按鈕移到左欄隊伍格下方。
