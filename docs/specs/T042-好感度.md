# T042 好感度（摸摸主頁角色）

## 目標
每個角色各自有一條好感度（0～10 級）。在主頁摸摸牠、帶牠一起出征就會慢慢增加，升級當場送禮物，讓玩家對每一隻角色多一點感情，也讓主頁那隻狗不只是擺著看。

待辦只剩要等 Jimmy 填項目的 T009，所以夜間先做這一項（主頁的狗本來點一下就會跳、冒愛心，但沒有任何作用；T041 做了小故事之後，接著讓角色「會回應」）。

## 範圍
做：
- `src/logic/bond.ts`：好感度的規則，全部是純函式
- 怎麼漲：
  - 在主頁摸摸主頁角色：每個角色一天一次 +10（05:00 換日）；今天摸過了再摸只會撒嬌，不再加
  - 一起出征：打贏每隻上陣的 +3、打輸 +1（主線、爬塔、老鼠幫、自動出征都算）
- 0～10 級，門檻累積 10／30／60／100／150／220／300／400／520／660
- 升級的禮物當場自動入袋，不用另外按領取：糧草 100 → 骨頭幣 10 → 自己的碎片 2 → 糧草 300 → 骨頭幣 30＋碎片 3 → 糧草 500 → 骨頭幣 30 → 碎片 5 → 糧草 1000 → 骨頭幣 100＋碎片 10
- 主頁：名牌多「♥等級」；摸的時候角色頭上冒一句話（好感度 0～2、3～6、7～10 三個階段口氣不同，3 級起會提到小故事裡牠喜歡的東西），升級跳提示
- 打完的結算面板：有角色好感度升級就多一行
- 角色資料視窗：犬種那一行後面多「♥等級」，小故事那一頁多一行「好感度」，寫進度與下一級的禮物
- 存檔多一個欄位 `bond`，舊存檔讀進來從 0 開始

不做：
- 好感度不影響攻擊、防禦、戰力（純收集與獎勵）
- 送禮物（把零食、家具送給角色）、在「我的家」裡摸角色
- 每個角色專屬的台詞、好感度解鎖的新故事
- 好感度的任務、成就、圖鑑統計

## 設計說明
- 存檔 `GameState.bond = { points, day, petted }`：`points` 以角色 id 為鍵記累積的好感度；`day`／`petted` 記今天摸過誰。等級每次由 `bondLevel(points)` 現算
- 禮物用現成的 `RatLoot`／`applyRatLoot`，所以碎片、糧草、骨頭幣的入袋和提示文字都沿用老鼠幫、信箱那一套
- 出征在 `settleBattle` 最後呼叫 `battleBond`；升級記在 `ExpeditionRecord.bondUps`，`resultNotes` 多一行（結算面板窄，只寫第一隻與一共幾隻）
- 主頁的測試狀態在 `window.__WGZ__.lobby.bond`（等級、點數、今天還能不能摸、剛說的話、可以摸的範圍）
- 數字都在 `bond.ts` 最上面的 `BOND`、`BOND_NEED`、`REWARDS`，要調只改那裡
- 台詞是三個階段共用的（`LINES`），不經過 `wt()` 換字，所以寫成狗貓都通用的句子
