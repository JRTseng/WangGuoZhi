# T027 狗擴到 50 種

Jimmy 2026-11-17：「狗狗的全部類型可以提升到50種，你先分配哪些是SSR/SR/R/N,後續我再視情況來調整」。

## 做了什麼

- 新增 20 隻，共 50 隻，全部用召募取得。犬種取自 `docs/BREEDS.md`，名字、性格、技能原創。
- 稀有度：N 14、R 16、SR 10、SSR 10。六種定位各 8～9 隻。
- 每隻都照犬種畫（`breedArt.ts` 的 `SPECS`；踏雪用哈士奇的畫法），有體型、預設台詞、大絕招姿勢。
- 新的 SR、SSR 共 8 隻，各有一件專屬裝備（抽到就送）。
