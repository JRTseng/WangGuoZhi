# T033 我的家

Jimmy 2026-11-17：「可以讓使用者有一個自己的家，提供一些家具，可以放五隻角色進去裡面，然後可以屋內的場景跟屋外的庭院或者草皮，
例如貓就是有貓跳台，狗的屋外可以泳池或者丟飛盤玩球球等等」「這個家的進入位置可以從主頁面多一個貓或者狗腳印的按鈕」
「家的地形與風格也提供15種讓使用者選擇」「家具類先提供50種」。

## 做了什麼

- **入口**：主頁右上那一排多一個腳印按鈕「我的家」，汪國是狗腳印、喵國是貓腳印。
- **兩個場景**：屋內、庭院，標題列右邊的按鈕切換。
- **住戶**：最多五隻。沒選過就先住目前的隊伍；按「住戶」可以換。牠們會自己走來走去，走到家具旁邊就玩那件家具：
  泡泳池、爬貓跳台、睡沙發、追球和飛盤、鑽紙箱、跳欄、吃飯、看魚……身上的裝備與飾品照樣看得到。
- **家具 50 種**（屋內 25、庭院 25）：按「家具」點一下擺出來或收起來；擺出來以後用手指按著拖到喜歡的位置，位置會記住。
  點一下家具會顯示名字與一句說明。全部免費、一開始就有。
- **地形與風格 15 種**：按「風格」換。一種風格同時換庭院的地形（天空、地面、遠景、圍籬，有的會飄雪、花瓣、落葉、螢火蟲）
  與屋內的配色（牆、地板、窗外的景色）。全部免費。
- **兩國一開始擺的不一樣**：喵國屋內有貓跳台、紙箱、毛線球，庭院有吊床與貓草；汪國屋內有軟軟的窩、玩具箱、大骨頭，庭院有泳池與飛盤。
  之後想擺什麼都可以，兩國的家具是同一份。
- 純外觀，不影響戰鬥數值。

## 程式

- `src/logic/home.ts`：家具與風格的資料、住戶／擺放／搬動的規則、讀檔檢查。存檔 `GameState.home = { residents, placed, area, style }`。
- `src/logic/homeLayout.ts`：版面與位置換算。
- `src/scenes/HomeScene.ts`：畫面、角色走動與玩家具、拖曳、三個彈出視窗。
- `src/scenes/components/furnitureArt.ts`（50 件家具的圖）、`homeArt.ts`（屋內與庭院的背景）。
