# T036 裝備升星

## 目標
Jimmy 2026-11-17：「後續再做裝備也可以升級星等」。裝備可以升星變強，重複撿到的同款裝備終於有用途。

## 範圍
做：
- 每種裝備有自己的星數，0～5 星；同款的每一件一起變強，穿在誰身上都算
- 每升一星，攻防合計多原本的 20%，而且至少 +1，照原本攻擊與防禦的比例分；有比例加成的專屬裝備每星再多 1%（5% → 滿星 10%）；爬塔飾品的功能不變
- 花的東西看裝備怎麼來的：
  - 關卡掉的一般裝備：吃掉多的同款，升到第 1～5 星各要 1／1／2／2／3 件（穿在身上的與最後一件不會被吃掉）
  - 專屬裝備（每隻只有一件）：花那隻角色的碎片 5／10／15／20／25
  - 爬塔飾品（每種只有一件）：花骨頭幣 50／100／150／200／250
- 倉庫畫面：卡片上顯示星數與升星後的數字；點卡片左邊的圖示開升星視窗（現在與下一星的數字、要花什麼、手上有多少）；圖示下緣的「升星」在材料夠時變成金色的「可升星」
- 標題列「全部升星」：一般裝備多的同款一次吃掉、能升的都升；不花碎片與骨頭幣（這兩樣還有別的用途）
- 「一鍵穿上」比較裝備時把星等算進去
- 星數存檔（`GameState.gearStars`），舊存檔沒有這個欄位就是全部 0 星

不做：
- 裝備的外觀不跟著星數變
- 關卡難度不跟著調
- 裝備分解、強化石之類的新材料

## 設計說明
- 星數記在裝備種類上，不是每一件各自記。裝備本來就只記「每種幾件」，改成每件各自有星數要重做存檔與穿脫，而且同款重複的裝備會變得很難管
- 加成的公式在 `src/logic/equipment.ts` 的 `gearAtStar`，`gearBonus`、`gearPct` 都經過它，所以訓練場、組隊、戰鬥的數字自動跟著變
- 升星的規則與花費在 `src/logic/gearStar.ts`（`checkGearStarUp`、`gearStarUp`、`gearStarUpAll`），花費表是 `GEAR_STAR_COPIES`、`GEAR_STAR_SHARDS`、`GEAR_STAR_BONES`
- 每一星至少 +1：只照 20% 四捨五入的話，R 裝備（合計 4）有幾星會升了數字沒變。滿星的合計是 N 7、R 9、SR 14、SSR 24、專屬 SR 20、專屬 SSR 32
- 版面在 `src/logic/gearLayout.ts`（`starAll`、`gearCardIcon`、`gearStarPanelButtons`）
