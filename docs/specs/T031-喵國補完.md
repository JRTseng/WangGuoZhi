# T031 喵國補完：貓 50 種、自己的劇情、自己的敵人

Jimmy 2026-11-17：「補到50種，劇情可以做設計不壹樣的比較有趣味跟耐玩性，敵人也可以改一下」。

## 做了什麼

- **貓補到 50 種**（`src/data/cats.ts`）：多 30 隻，合計 N 14／R 16／SR 10／SSR 10，和汪國一樣多。
  每隻都有照品種畫的樣子、大絕招台詞與姿勢；新的 SR、SSR 十二隻各有一件專屬裝備。
- **喵國自己的劇情**（`src/data/catStories.ts`）：十二段，和汪國完全不同的故事。
  倉庫的罐頭只夠吃到月底，要湊齊十塊「九命鈴」打開傳說中的萬罐庫；每一章的頭目各守著一塊。
  開放條件和汪國那一套一樣（序章一開始就有，其他跟著過關開）。
- **喵國自己的敵人**（`src/data/world.ts`）：加入喵國後，十章的敵人換成各地的野貓幫，頭目換成十隻野生貓科；
  登天塔的守層也跟著換成貓。主線任務裡「打倒某頭目」的名字跟著陣營走。
- **數值不變**：敵人的攻防、關卡難度、獎勵、積分都和汪國同一關一樣，只換名字、樣子與故事。

## 怎麼切換

`applyWorld(faction)` 在存檔載入與每次存檔內容更新時呼叫，會把 `REGIONS`（章節說明、幫派名、頭目）、
`STORIES`、登天塔一起換成那個陣營的版本。還沒選陣營當成汪國。
