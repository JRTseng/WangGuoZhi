# T025 像素立體光影畫面（第一步：場景、主頁、戰鬥）

## 目標
Jimmy 2026-11-16 貼了一張參考圖，想把整體畫面改成那種風格：像素質感的場景，加上前後景的層次與失焦、暖色的光暈與光束、飄在空中的光點、隨時段變化的光線。
只取這個畫面方向，場景、角色、介面全部是汪國志自己的原創內容，題材維持狗狗三國。

範圍很大，分幾步做。這一步先把共用的畫法做好，套到所有用到場景背景的畫面，重點是主頁和戰鬥。

## 範圍
做：
- 場景背景的新畫法（主頁、戰鬥、出征地圖、劇情、接飛盤小遊戲共用同一套，所以一次全部換掉）：
  - 像素化：場景照小小的尺寸畫，再一格一格放大
  - 景深：最遠的天空與遠山失焦模糊，畫面最前面兩個角落有失焦的草叢
  - 光影：光源的柔光、從光源灑下來的光束、地平線的霧氣、四角暗角
  - 粒子：飄在空中的光點（原本的落葉、花瓣、雪、火星都還在，也變成像素）
  - 地面加上深淺的小碎點，不再是一整片平的顏色
- 主頁的光線跟著手機的時間換：清晨、白天、黃昏、夜晚；夜晚光點變螢火蟲。本來就是晚上的場景（雪嶺、霧沼、焰嶺、燈會、汪都）不變
- 站在場景裡的狗變成像素畫風：主頁的狗、戰鬥的頭像、大絕招演出、劇情說話的狗、接飛盤的狗
- 跟著畫質設定降級（見下面）

不做（之後幾步）：
- 按鈕、卡片、面板等介面的重新設計
- 組隊、訓練場、倉庫、召募等介面畫面裡的狗（卡片上的小頭像像素化會糊掉，要另外處理）
- 每張場景重新畫得更細（加建築的明暗面、影子、更多層次）
- 四季、天氣（下雨、起風）
- 戰鬥畫面跟著時段換光線

## 設計說明
參考圖那種畫面是用 3D 場景貼像素圖做的。汪國志是 2D 遊戲、沒有 3D 鏡頭，所以用 2D 的方式做出同樣的觀感：分層、失焦、打光。沒有加任何新套件，也沒有圖檔，全部還是程式畫的。

- 圖層由後往前（`src/scenes/components/Scenery.ts`）：
  1. 遠景（每張場景最後面那一層：天空、遠山）畫成像素圖再模糊
  2. 中景：整個場景畫進一張 422 x 195 的小圖，用最近點放大成 844 x 390，就是一格 2 點的像素畫。會動的東西（雲、落葉、水波）也在這張圖裡，所以一樣是像素。約每秒重畫 30 次
  3. 時段色調（整張乘上一個顏色）、地平線霧氣、光源柔光、光束、光點（都是加亮混色的柔光貼圖）
  4. 近景失焦草叢、暗角
- 模糊不是每一格即時算的：建立畫面時把小圖錯開疊幾次算平均（`blurSheet`），之後每一格只是貼圖，手機不用多花力氣。
- 柔光、光束、暗角三張貼圖是用畫布當場畫的漸層（`src/scenes/components/pixelStage.ts`），整個遊戲只畫一次。
- 每張場景的光線設定（光的顏色、光源位置、幾道光束、霧氣、草叢顏色）與各時段的色調都在 `src/logic/atmosphere.ts`，要調好不好看改這個檔就好。像素大小是同一個檔的 `PIXEL_SIZE`（現在是 2）。
- 像素狗：狗還是原本那套畫法，畫完以後把尾巴、身體、裝備、頭、眼皮各自拍成像素圖（`pixelize`），所以原本的動作（搖尾巴、跳、打盹、大絕招姿勢）都不用改。`DogSprite` 多一個 `pixel` 選項，不給就是原本平滑的線條（倉庫等介面畫面目前還是平滑的）。
- 主頁的狗會跟著時段的色調染一點顏色（四成），才像是站在場景裡。

### 畫質與效能
- 低：場景完全不動，所有圖層壓成一張圖，每一格只貼這一張，比改版前還省。沒有光點。
- 中：光點 8 顆、飄落物 10 個。
- 高：光點 18 顆、飄落物 24 個。
- 中景那張小圖只有 422 x 195，不管手機解析度多高都一樣大，所以會動的場景本身比以前省；多出來的是幾張整個畫面大的柔光貼圖。
- 「戰鬥特效」開關管的是大絕招的特效，和這次的場景光影無關，沒有動它。

## 第二步（樣本）：精緻版場景與照犬種畫的狗

Jimmy 2026-11-16 看過第一步後說：以為會是比較精美的背景和角色；角色應該稍微寫實、帥氣或可愛一點，「根據真實狗狗的模樣去設計角色，例如哈士奇、博美、柴犬」。
第一步只換了畫法，場景和狗本身還是簡單的形狀。這一步先做樣本給 Jimmy 看方向：

- 落葉坡重畫（`sceneryArt.ts` 的 `slope`，零件在 `src/scenes/components/sceneryRich.ts`）：三層遠山與遠方樹林、村口的樹林、彎進村口的泥土路、有亮暗面的木柵欄與瞭望台、腳印旗、稻草捆、枝葉有三層明暗的大楓樹、往左下拉的影子、草地紋理與光斑。其他 11 張還是舊的畫法。
- 照犬種畫的狗（`src/scenes/components/breedArt.ts`）：柴犬（寬臉、裏白、眉上白點、捲尾）、哈士奇（高尖耳、深色面罩、藍眼睛、白腹、鐮刀尾）、博美（一圈蓬毛、小耳朵、短腿、羽毛尾）。每個犬種有自己的頭、身體、尾巴畫法；`BREED_ART` 的鍵是 `dogs.ts` 的 `breed`，沒畫的犬種照舊用通用畫法。
- 所有畫狗頭的地方（主頁、戰鬥、大絕招、組隊卡片、訓練場、召募、結算等）都會照犬種畫；還沒擁有的暗色剪影維持通用的樣子。
- 毛色照舊用每隻狗自己的 `color`／`accent`，所以同犬種可以有不同毛色。

待 Jimmy 決定：這個方向（可愛偏寫實的像素狗）對不對；對的話剩下 27 個犬種與 11 張場景分批做。
