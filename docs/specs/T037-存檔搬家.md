# T037 存檔搬家（匯出／匯入）

## 目標
玩家可以把整份進度變成一串「存檔碼」帶走，在另一支手機、另一個瀏覽器，或 iPhone「加到主畫面」的版本貼上讀回來。
現在的存檔只留在當下那個瀏覽器裡（T006），iPhone 的 Safari 與主畫面版又是分開的兩份（T012 的待決定），換地方就得從頭玩。

待辦只剩 T009（要 Jimmy 先填項目），夜間照「待決定」裡 T012 那一條的建議先做這個。全部單機，不接帳號與雲端。

## 範圍
做：
- 設定面板最下面一列多一顆「存檔搬家」
- 存檔搬家視窗（一般網頁的視窗蓋在遊戲上，才能貼上文字、選檔案）
  - 帶走：顯示現在這份進度的摘要；「複製存檔碼」「存成檔案」
  - 讀取：貼上存檔碼（或「貼上」「選檔案」），按「讀取」先顯示那份進度的摘要，再按一次「確定讀取」才蓋掉
  - 讀取前，現在的進度先留一份備份；視窗裡有「還原讀取前的進度」
- 存檔碼的編碼、解碼與檢查（`src/logic/saveTransfer.ts`）：壓縮、檢查碼、看不懂／沒複製完整／版本太新都講得出原因

不做：
- 帳號、雲端同步、自動備份
- QR code、分享選單
- 兩份進度合併（讀取就是整份換掉）

## 設計說明
- 存檔碼格式：`WGZ1.<z 或 r>.<內容>.<檢查碼>`。內容是 T006 那份存檔 JSON，`z` 是壓縮過（deflate-raw）、`r` 是沒壓縮（瀏覽器沒有壓縮功能時），再轉成只有英數與 `-_` 的 base64url。檢查碼是內容的 FNV-1a（8 個十六進位字），少複製一截就對不上。
  解碼時先把空白與換行全部拿掉（通訊軟體會自動斷行）。
- 讀進來的 JSON 交給 T006 的 `deserialize` 檢查與補欄位，所以舊版的存檔碼在新版遊戲讀得進來；存檔格式版本比遊戲新的不收（請玩家先更新遊戲）。
- 摘要（`saveSummary`）：陣營、城主等級、角色數、通關關數、存檔時間。讀取前給玩家看一眼，免得貼錯。
- 讀取：`store.importSave` 先把現在的存檔寫到 `wgz-save-before-import`，再換成新的並重新整理頁面。「還原」是把兩份對調，所以還原本身也能再還原。
- 壓縮是非同步的，Safari 又規定寫剪貼簿一定要在點按的當下，所以視窗一開就先把存檔碼算好，按鈕按下去只做「寫進剪貼簿」。
- 視窗用一般網頁元素（和 T017 改台詞的視窗同一種做法），測試用 `data-act` 找按鈕，狀態放在 `__WGZ__.transfer`。
