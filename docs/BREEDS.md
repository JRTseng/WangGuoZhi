# 犬種參考表

Jimmy 2026-11-12 建議：世界上的狗狗品種很多樣，新增角色時參考真實犬種的特徵。這份表給 T007 抽卡招募（與之後新增角色）挑犬種用。

用法：

- 角色的外型、性格、定位從犬種特徵出發，維持 GDD「犬種對應性格」的原則。
- 名字、技能、故事一律原創，不對應史實人物，也不使用任何既有作品的角色。
- 體型分小／中／大，對應 T007 的體型欄位；「適合定位」只是建議，可以故意做反差（例如小型犬當前排）。
- 表內是一般公認的犬種特徵，用來找靈感，不是飼養建議。

現有角色與 Boss 已用掉的犬種：柴犬、拉布拉多、阿富汗獵犬、邊境牧羊犬、薩摩耶、德國牧羊犬、柯基、哈士奇；Boss 用了高山犬、大丹犬、藏獒。

## 給 T007 的建議

- 新增的 10 隻先各體型都挑幾隻，定位也分散，讓篩選與組隊有東西可選。
- 第 1 章 Boss 獎勵的補血狗（T017）可以從聖伯納犬、紐芬蘭犬、黃金獵犬裡挑，救援犬的形象很合。
- 高稀有度可以留給外型辨識度高的犬種（例如高加索犬、聖伯納犬、蘇俄牧羊犬、台灣犬）。
